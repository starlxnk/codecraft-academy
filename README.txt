# 🎓 CodeCraft Academy — Fullstack EdTech Platform Landing Page

Интерактивная образовательная IT-платформа с динамическим каталогом, калькулятором рассрочки и полноценной интеграцией с облачной базой данных PostgreSQL (Supabase) для обработки заявок и оплат в реальном времени.

## 🚀 Ключевой функционал

- **BaaS & Cloud Database:** интеграция с Supabase SDK для записи транзакций и данных студентов напрямую в табличную базу данных PostgreSQL (`enrollments`).
- **Каталог курсов:** динамическая фильтрация по категориям (Программирование, Дизайн, AI & Data Science) без перезагрузки страницы.
- **Интерактивный калькулятор:** мгновенный расчёт ежемесячного платежа по рассрочке в зависимости от длительности и стоимости выбранной программы.
- **Эквайринг & Оплата:** модальное окно записи с масками ввода номера карты, валидацией данных и тост-уведомлениями.
- **Адаптивный Dark Glassmorphic UI:** современный интерфейс в неоново-темных тонах, оптимизированный под любые разрешения экранов.

---

## 🛠️ Стек технологий

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Properties, Flexbox, Grid).
- **Backend & Database:** Supabase JS Client, PostgreSQL.
- **UI/UX:** Glassmorphism, Google Fonts (Plus Jakarta Sans).
- **Hosting:** GitHub Pages.
