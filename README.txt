# 🎓 CodeCraft Academy — EdTech Platform Landing Page

Интерактивный лендинг современной образовательной IT-платформы с калькулятором рассрочки, системой фильтрации курсов и эмуляцией процесса оплаты.

---

## 🚀 Ключевой функционал

- **Каталог курсов:** динамическая фильтрация по категориям (Программирование, Дизайн, AI & Data Science) без перезагрузки страницы.
- **Интерактивный калькулятор:** расчёт ежемесячного платежа по рассрочке в зависимости от длительности и стоимости курса.
- **Эквайринг & Оплата:** модальное окно записи с автоформатированием номера карты (пробелы) и валидацией данных.
- **Интерактивный UI:** аккордеоны программы обучения и FAQ, всплывающие Toast-уведомления и плавные модальные окна.
- **Адаптивный дизайн:** чистый Glassmorphism в тёмных тонах, оптимизированный под мобильные устройства и планшеты.

---

## 🛠️ Стек технологий

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Properties, Flexbox, Grid).
- **UI/UX:** Glassmorphic UI, Google Fonts (Plus Jakarta Sans).
- **Hosting:** GitHub Pages.
